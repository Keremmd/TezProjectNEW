# LearnAI - AI-Powered Collaborative Learning Platform

## 🚀 Frontend Application

Modern ve profesyonel bir kullanıcı arayüzü ile yapay zeka destekli öğrenme platformu.

### ✨ Özellikler

- 🎨 Modern ve responsive tasarım
- 🌈 Gradient ve animasyonlu UI componentleri
- 🔐 Güvenli authentication sistemi (Login/Register)
- 📱 Mobile-first yaklaşım
- ⚡ Lightning-fast Vite build tool
- 🎯 React Router ile sayfa yönetimi

### 🛠️ Teknolojiler

- **React** - UI kütüphanesi
- **Vite** - Build tool
- **Tailwind CSS** - Styling
- **React Router DOM** - Routing
- **Lucide React** - Icon kütüphanesi

### 📦 Kurulum

```bash
# Dependencies'leri yükle
npm install

# Development server'ı başlat
npm run dev

# Production build
npm run build

# Build preview
npm run preview
```

### 🌐 Sayfalar

- **Landing Page** (`/`) - Ana sayfa, özellikler ve CTA
- **Login** (`/login`) - Kullanıcı girişi
- **Register** (`/register`) - Yeni kullanıcı kaydı
- **Dashboard** (`/dashboard`) - Kullanıcı paneli (yapım aşamasında)

### 🎨 UI/UX Özellikleri

- Gradient backgrounds ve glassmorphism
- Smooth animations ve transitions
- Hover effects ve interactive elements
- Social login integration (Google, GitHub)
- Form validation ve error handling
- Loading states

### 📝 Gelecek Özellikler

- Dashboard implementasyonu
- PDF upload ve işleme
- AI özet görüntüleme
- Quiz oluşturma ve çözme
- Sosyal paylaşım özellikleri
- Profil yönetimi

### 🔗 Backend Entegrasyonu

Backend API'si hazır olduğunda JWT authentication ve REST API entegrasyonu yapılacaktır.
